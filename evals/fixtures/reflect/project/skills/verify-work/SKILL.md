# Verify Work

## Process

1. Read the requested acceptance criteria and the project's validation commands.
2. Run the applicable commands and summarize their output.
3. Compare version fields across plugin manifests before handoff.
4. Report results and remaining limitations.

For a review-only request, inspect and report; do not edit files or make commits.
